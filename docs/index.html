Bagaimana Sistem Ini Berfungsi?

Bayangkan sistem ini seperti seorang pengawal sekolah yang mempunyai mata yang sangat tajam dan sebuah buku daftar murid yang lengkap!

Langkah 1
📷

Mata Kamera (Webcam)

Kamera menangkap gambar secara berterusan (30 bingkai sesaat) menggunakan perpustakaan OpenCV dalam Python.

💡 Ibarat mata pengawal yang memerhati kereta lalu lalang di pintu pagar.
Langkah 2
🧠

Otak AI (Kunci API)

Gambar dihantar ke model AI Vision (Gemini atau OpenAI) menggunakan kunci API peribadi anda untuk membaca nombor plat atau mengenali wajah.

💡 Ibarat otak pakar yang boleh membaca teks kecil dan mengenali wajah sekelip mata.
Langkah 3
📚

Buku Daftar (SQLite3)

Komputer menyemak pangkalan data: "Adakah kereta ini kepunyaan guru bertugas?" atau "Adakah murid ini dalam kelas 5 Arif?"

💡 Ibarat buku pendaftaran sekolah yang tersusun rapi dalam kabinet fail.
Langkah 4
✅

Tindakan Automatik

Jika padanan dijumpai, sistem mencatat rekod kehadiran, membuka palang automatik, menghantar notis, atau menyimpan tangkapan gambar ke log.

💡 Ibarat pengawal memberi salam dan menekan butang buka pagar!
🔑

Mengapa Konsep BYOK (Bring Your Own Key)?

Setiap penyelidik atau pelajar memiliki kunci AI API sendiri. Tiada yuran langganan pihak ketiga, tiada perkongsian data, dan anda mempunyai kawalan penuh ke atas had penggunaan API anda.

⚡

Mengapa Pangkalan Data SQLite3?

SQLite3 hanya berupa satu fail kecil (ai_webcam.db). Sangat laju, tidak memerlukan pemasangan pelayan rumit, berfungsi tanpa sambungan internet, dan mudah untuk dibawa dan dikongsi sebagai fail biasa.

Inovasi Sekolah & Pertandingan STEM

6 Idea Projek Sekolah Menggunakan Sistem Ini

Sesuai untuk pameran sains, pertandingan inovasi STEM, atau kerja kursus RBT dan Sains Komputer!

Trafik & Keselamatan 🚧

1. Palang Pintu Automatik untuk Kereta Guru

Webcam di pondok pengawal membaca nombor plat kereta guru. Jika plat disenaraikan dalam SQLite3, motor servo Arduino membuka palang secara automatik tanpa kehadiran pengawal fizikal.

  • Mod AI: Nombor Plat (ANPR)
  • Perkakasan: Arduino / Raspberry Pi (Pilihan)
  • Tahap: Menengah Rendah & Atas
☁️ Cloud API Google Gemini 2.0 Flash
☁️ Alternatif GPT-4o mini (OpenAI)
🖥️ Lokal <8GB RTX LLaVA 1.6 7B (via Ollama)
Pengurusan Sekolah 🏫

2. Sistem Kehadiran Murid Tanpa Sentuhan

Murid berjalan melepasi kamera di pintu kelas. Sistem mengenal wajah, menanda kehadiran dalam SQLite3, dan menghantar notifikasi kepada ibu bapa — semua dalam masa bawah 2 saat.

  • Mod AI: Pengecaman Wajah (Face ID)
  • Perkakasan: Webcam Makmal Komputer
  • Tahap: Sekolah Rendah & Menengah
☁️ Cloud API Google Gemini 2.0 Flash (Vision)
🔧 Lib Khusus face_recognition + DeepFace
🖥️ Lokal <8GB RTX InsightFace ArcFace R50 (ONNX)
Pendidikan Khas 📖

3. Pembaca Teks Bersuara untuk Rakan OKU Penglihatan

Rakan meletakkan buku atau kad imbasan di bawah webcam. AI membaca semua teks melalui OCR dan membacakannya secara lantang menggunakan Text-to-Speech — membantu rakan yang mempunyai masalah penglihatan.

  • Mod AI: Pengecaman Huruf (OCR Vision)
  • Perkakasan: Speaker / Fon Telinga
  • Tahap: Semua Peringkat Umur
☁️ Cloud API Google Gemini 2.0 Flash (Vision)
☁️ Alternatif GPT-4o (OpenAI Vision)
🖥️ Lokal <8GB RTX Tesseract OCR 5 + PaddleOCR (CPU/GPU)
Kelestarian Alam ♻️

4. Tong Kitar Semula Pintar Sekolah

Murid menunjukkan sampah ke hadapan webcam. AI mengenal pasti jenis bahan (plastik, aluminium, kertas) dan menghidupkan lampu LED penunjuk tong yang betul secara automatik.

  • Mod AI: Penganalisis Objek (Scene AI)
  • Perkakasan: LED & Tong Berlabel Warna
  • Tahap: Kelab Alam Sekitar & STEM
☁️ Cloud API Google Gemini 2.0 Flash (Vision)
☁️ Alternatif Claude 3.5 Haiku (Anthropic)
🖥️ Lokal <8GB RTX Moondream2 2B (via Ollama)
Kawalan Keselamatan 🔐

5. Pengawal Makmal Komputer Waktu Malam

Selepas waktu sekolah, kamera mengesan pergerakan. Jika wajah yang dikesan bukan staf bertugas, siren berbunyi dan gambar dihantar terus ke emel pentadbir sekolah.

  • Mod AI: Pengecaman Wajah + Pengesan Pergerakan
  • Perkakasan: Speaker & Sambungan Email
  • Tahap: Menengah Atas
☁️ Cloud API Google Gemini 2.0 Flash (Vision)
🔧 Lib Khusus DeepFace + OpenCV Motion
🖥️ Lokal <8GB RTX InsightFace R50 + YOLOv8n (ONNX)
Analisis Sukan & Tinju Biomekanik 🥊

6. Sistem Analisis Prestasi Sukan & Biomekanik Tinju

Kamera merakam atlet semasa latihan larian atau sukan tinju. AI menganalisis biomekanik terperinci — merangkumi aturan tumbukan (Jab, Cross, Hook, Uppercut), kedudukan kaki & pendirian (Orthodox vs Southpaw), kawalan bunga pertahanan (High Guard), dan kombinasi rantaian kinetik — serta menjana diagnosis kelajuan, skor postur, dan cadangan dril penambahbaikan khusus.

  • Disiplin: Sukan Olahraga (Larian) & Sukan Tinju (Pukulan, Stance, Guard, Bunga)
  • Mod AI: MediaPipe Pose Landmarker + Multimodal Vision Biomechanics
  • Teknologi: MediaPipe Pose + Google Gemini / Ollama Vision
  • Output: Studio Sukan Interaktif, Tolok Sudut Sendi Langsung & Simpanan Sesi SQLite
☁️ Cloud API Google Gemini 2.0 Flash (Vision + Text)
🔧 Lib Pose MediaPipe Pose Landmarker (Google)
🖥️ Lokal <8GB RTX YOLO11-Pose + LLaVA 7B (via Ollama)
Panduan Memulakan Projek

Cara Memulakan Projek AI-WebCam

Ikuti 4 langkah mudah ini untuk mula menjalankan sistem di komputer anda.

1

Pasang Python dan Muat Turun Kod Projek

Pastikan Python 3.10 atau lebih baharu sudah dipasang. Kemudian muat turun dan sedia persekitaran projek ini.

git clone https://github.com/sabilyent/AI-WebCam.git cd AI-WebCam pip install -r requirements.txt
2

Dapatkan Kunci AI API Percuma Anda

Untuk pelajar dan penyelidik, dapatkan Google Gemini API Key secara percuma melalui Google AI Studio. Ia percuma untuk tujuan pelajaran dan ujian.

⚠️ Penting: Kunci API anda adalah rahsia peribadi anda. Jangan kongsikan kepada sesiapa dan jangan upload ke GitHub tanpa perlindungan!
3

Masukkan Data Rujukan ke SQLite3

Gunakan papan pemuka web atau skrip Python mudah untuk mendaftarkan nombor plat kenderaan dan gambar wajah murid/guru ke dalam pangkalan data data/ai_webcam.db anda.

4

Jalankan Sistem dan Lihat Ia Berfungsi!

Mulakan aplikasi dengan satu arahan mudah, kemudian buka papan pemuka di pelayar web anda:

python app.py

Buka pelayar anda dan pergi ke http://localhost:5000 untuk melihat suapan kamera langsung dengan analisis AI.
